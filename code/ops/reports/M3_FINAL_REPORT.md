## 三、地图观察模式

- 地图 canvas 尺寸严格等于视口：`1600×900` 实测 `1600×900`；`html/body/#app` 均 `overflow:hidden`，
  `scrollHeight === clientHeight`（三种分辨率均验证）。
- 底部只有一条悬浮时间轴，**时间轴下方没有任何内容块**（E2E 按 `top >= 时间轴底部` 反查，结果 0 个）。
- 事件标记按「时间窗口 ∩ 当前视野」查询，一个「事件 × 地点」一个要素；同一事件关联多地点时按真实地点分别出点。
- 聚合：MapLibre `cluster: true`，圆点半径随 `point_count` 分级（不依赖字体，离线降级底图下也能渲染）；
  点聚合圈 → `getClusterExpansionZoom` 放大；点单点 → 详情。
- 坐标约束沿用 M1：`geom` 非空、`crs_confidence <> 'unknown'`、地点/位置未被否决、地点未合并、源记录 active。
  **未知坐标不生成假点**。
- 图层默认只开「事件」；「地点」图层（M1）可在右下角开关，默认关闭以免两个图层互相干扰。

## 四、历史时空矩阵

- 顶部刻度 = `N` 列，列宽随跨度（1年 76px / 10年 98px / 100年 108px）。
- **对齐由结构保证**：刻度行与数据行在**同一个横向滚动容器**内，左侧「地区 / 政权」列 `position: sticky; left:0`，
  表头 `position: sticky; top:0`。E2E 实测：滚动 300px 后，表头列与单元格同一列位移完全一致（190/190 → -110/-110），
  左侧列 `left` 始终为 0。
- 列数按视口自适应（`ceil((视口-左列)/列宽)+6`，上限 48），保证首屏就能滚动；滚到右侧 240px 内自动追加下一页，
  后端返回**绝对列号**，追加后索引连续不跳列。
- 地区固定 10 个、默认全部收起、可同时展开多个；空单元格留白；无可信事件政权不显示；
  跨多年事件在所有相交列都出现；一个事件关联多政权时在对应多行分别出现；单元格最多直显 2 条 + `+N`（可点）。
- 顶部导航在展开时保持可见（矩阵让出 56px），不出现大标题/说明区块（E2E 断言 `.mx h1/h2` 为 0）。

## 五、时间处理与 BCE/CE

- 全部用天文学纪年整数；换算与显示只在 `frontend/src/time.ts` 与后端 `TimeMapService` 各一处（规则同源，前端不算业务）。
- 区间端点包含式：`start <= windowEnd && coalesce(end, start) >= windowStart`。
- 只知起点（end 为空）的事件**按起点单年**参与窗口匹配，不向未来无限延伸（否则一个「始于前500」的事件会出现在此后每一个窗口）。
- 起点未知的事件不进入地图与矩阵，仍保留在内容管理中；地图 meta 与矩阵 meta 都会报出这类事件数量。

E2E 实测（真实点击）：

```
U12 跨度 1 年显示「公元 1 年」            实际 2 → 公元 1 年
U13 再往前一年显示「公元前 1 年」         实际 公元前 1 年      ← 不出现「公元 0 年」
U14 继续往前是「公元前 2 年」             实际 公元前 2 年
U16 矩阵表头不含「0」                     实际 前500/前490/…（无 0）
```

接口实测：`T09/T10` 内部 0 与 1 均可查询；`T11` 跨前后窗口列标签为 `-4..5` / `6..15`；
`T07/T08` 端点包含式（事件 -585..-537，窗口 -537 命中、-536 不命中）。

## 六、历史政权模型与关联

`historical_polity`：`polity_id / name / name_lang / region_code / start_year_astro / end_year_astro /
description / notes / record_status / created_at / updated_at`。

- `region_code` 是**展示分组**（10 个固定值，CHECK 约束），不是历史疆域判定。
- 存在区间可选，**不参与矩阵过滤**——矩阵只看事件时间；政权是否出现取决于它在窗口内有没有事件。
- `event_polity`：(event_id, polity_id) 唯一；删事件 → 关联随 CASCADE 消失；删政权 → 关联消失但**不删事件**。
- **不存在任何自动归属逻辑**：没有按事件名称匹配、没有按坐标/现代国界推断。全部关联都是人工建立的。
- 未关联政权的事件仍完整保留，矩阵接口返回 `unlinkedEventsInWindow`，界面右上角显示「未关联政权 N 条」。

数据真实性：种子数据只进测试库（`ops/m3/seed_demo.sql`，事件标题统一以「演示：」开头），
正式库未写入任何测试数据。

## 八、API 变更

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/events/map?bbox=w,s,e,n&from=&to=&limit=` | 事件标记 GeoJSON；`limit` 默认 1200、上限 3000；meta 含 `totalInWindow/truncated/unknownTimeEvents` |

| GET/POST | `/api/v1/events/{id}/polities` | 查询 / 添加关联（重复 → 409） |
