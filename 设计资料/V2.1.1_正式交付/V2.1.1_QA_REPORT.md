## 3. 本轮已修正的实际问题

### 3.1 来源证据视图保留人工子行

- `v_place_evidence` 的 name/location 分支统一改为 `LEFT JOIN source_record`，避免 `source_record_id IS NULL` 的人工子行在分支内部被提前丢弃。
- 有效证据统一使用 `source_is_active IS TRUE AND child_record_status IS DISTINCT FROM 'rejected'`。源活性为 NULL 的人工子行可以保留用于追溯，但不被误算为有效源证据，也不会因 PostgreSQL `DESC` 的 NULL 默认排序而排到有效证据之前。
- `v_place_liveness` 对 `source_record` 使用 `LEFT JOIN`，既能读取 `inactive_at` / `inactive_in_batch_id`，也保留无源记录的人工子行供人工拒绝计数。
- CORE 与 DATA_PROVENANCE 中的 `v_place_evidence`、`v_place_liveness` SQL 已逐字比对一致。

### 3.2 回滚统计参数统一

- 导入期失败统一称为 `N_fail_import`。
- 回滚期 UPDATE 失败统一称为 `N_fail_rb`。
- R2c 统一使用回滚批次 `:Rb`，不再错误地使用被回滚批次 `:R`。
- IMPORT_RULES 不再复制一套与 ROLLBACK 文件存在差异的回滚状态机，改为引用唯一完整定义。

### 3.3 重复隔离示例纠正

- Pleiades `external_id=20469` 的三条记录按 `parent_external_id` 分属两个自然键组，不再错误描述为同一个 `A,A,B` 混合组。
- `A,A,B → A,A,B,B` 的转变按 A、B 两个相同 hash 子组分别保留最小 ordinal，后续副本隔离，隔离数修正为 **2 行**。

### 3.4 ER 与映射文件修正

- ER 图恢复子表 `record_status` 的真实枚举字面量 `published`；D3-3 的检查范围限定为 `v_place_time_span` 过滤条件，不再错误要求整个 ER 图不出现该值。
- ER 图的 canonical 顺序补全为 6 个排序键，并注明 canonical 追溯标记不等同于有效证据。
- FIELD_MAPPING 删除失效的 CORE 快照哈希引用，文件快照统一由最终冻结文件维护。
- DATA_PROVENANCE 补充权威依据声明。

### 3.5 质量台账枚举说明

`issue_type` 保留 19 个值。按当前暂存原始口径，删除 2 条旧类型记录后，19 个目标值的命中数合计 **12,629**；其中 7 个值在当前暂存台账中为零命中，已逐项说明其属于导入期、派生期、人工保护或回滚运行期用途，不代表当前暂存数据中已有对应记录。
