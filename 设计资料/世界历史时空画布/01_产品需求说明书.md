# 01｜产品需求说明书（V1.0）

## 1. 核心使用场景

### 场景 A：按时间观察世界

用户选择一个年份或时间范围，地图显示该时间范围内已收录的历史事件和地点。用户可以看到同一时期不同地区发生的事情，而不是只沿着单一国家或文明阅读。

### 场景 B：从事件进入

用户点击地图上的事件标记，查看事件名称、时间、描述、相关人物、相关地点和来源；可以继续点击人物或地点进入对应详情。

### 场景 C：从人物观察

用户选择一个历史人物，查看基本信息、生卒时间、相关事件和有资料支持的活动地点。地图突出显示相关地点；若有多个带时间信息的地点，可以按时间顺序显示示意连线。

路线连线仅表示已记录地点的顺序关系，不得伪装成史料确认的真实行进路线。

### 场景 D：从地点观察

用户点击一个历史地点，查看历史名称、别名、代表坐标、定位精度、可选现代地名、相关事件和人物。

### 场景 E：手动补充与纠错

用户可以手动新增、查看、编辑、删除地点、人物和事件。时间作为这些对象的属性维护，不提供独立时间对象的
CRUD。

## 2. 主界面建议

采用”中央地图 + 底部时间轴 + 侧边详情/编辑面板”的布局。

| 区域         | 职责                                                                     |
|:-------------|:-------------------------------------------------------------------------|
| 中央地图     | 显示当前时间范围内的历史地点、事件点和必要区域；支持拖动、缩放和底图切换 |
| 底部时间轴   | 选择公元前/公元后年份、单年或区间；调整观察窗口                          |
| 导航与筛选   | 进入事件、人物、地点观察入口；按类型和关键词筛选                         |
| 侧边详情面板 | 显示当前选中对象；提供编辑、删除和关联对象跳转                           |
| 搜索         | 搜索古地名、别名、现代参考地名、人物和事件                               |

具体 UI 布局允许在原型阶段优化，但地图必须保持主视觉和主要操作区域。

## 3. 地图需求

- 全球可浏览。
- 默认 Outdoor 户外地形主题。
- 支持 Streets / Base、Satellite、Hybrid 等已验证样式。
- 样式切换不应重置当前地图中心点、缩放级别和时间选择。
- 显示项目自有历史信息图层，不修改 MapTiler 底图要素。
- 地点可表达为点或区域；事件通过关联地点显示。
- 同一地点多个事件在低缩放级别应聚合，避免标记重叠。
- 没有可靠位置的事件可以只显示在列表中，不强制落点。
- 地图加载失败时，不能导致本地对象管理功能整体不可用。

## 4. 时间需求

- 用户界面使用传统公元前（BCE）和公元后（CE）表达，不显示公元 0 年。
- 支持单年和时间区间观察。
- 支持持续事件在其时间范围内被查询到。
- 支持日期精度不确定的记录。
- 未知年代事件可以保存，但默认不出现在某个明确年份的地图结果中；可通过”年代未知”筛选查看。
- V1 不建设独立时间对象或时间表。

## 5. 地点需求

最少字段： - 历史规范名称（必填）。 - 别名 / 异体名 / 外文名（可选）。 -
代表坐标（可为空）。 - 空间几何（可选，点或区域）。 -
定位精度（必填或有默认值）。 - 不确定范围（可选）。 -
可选现代地名参考。 - 数据来源与外部 ID（如来自导入数据）。

地点不要求必须对应现代同名城市。坐标未知时标记未定位，不得编造坐标。

## 6. 人物需求

最少字段： - 规范姓名（必填）。 - 别名 / 异体名 / 外文名（可选）。 -
生年、卒年（可未知或不确定）。 - 简介（可选）。 - 相关事件。 -
有资料支持的活动地点及其时间信息（可选）。

人物路线可以基于多个有时间顺序的活动地点绘制示意连线，但必须标明其为地点序列示意。

## 7. 事件需求

最少字段： - 事件标题（必填）。 - 时间信息（可标记未知）。 -
描述（可选）。 - 事件类型（可选）。 - 关联人物（可多个）。 -
关联地点（可多个）。 - 来源或参考资料（可选）。

一个事件可以涉及多个地点和人物；一个地点或人物可以关联多个事件。

## 8. 编辑与删除

- 地点、人物、事件均支持新增、查看、编辑、删除。
- 删除前显示关联影响。
- 默认禁止无提示级联删除其他对象。
- 对存在关联的对象，先提示用户解除关联或确认后续处理。
- 具体采用硬删除还是软删除，在数据库详细设计时冻结；不得自行实现静默级联删除。

## 9. 搜索与筛选

- 地点：规范名称、别名、现代参考地名。
- 人物：规范姓名、别名。
- 事件：标题、描述关键词。
- 时间：年份、时间区间、年代未知。
- 地图：当前视野范围、事件类型、人物、地点。

## 10. 非功能要求

- 桌面端优先，地图显示空间充足。
- 首屏不等待全球历史数据加载完成。
- 按当前时间范围和地图视野加载数据。
- 允许数据不完整，不以空值阻塞录入。
- 地图与业务数据解耦，未来可以替换地图供应商。
- V1 面向个人使用，不建设复杂用户权限系统。
