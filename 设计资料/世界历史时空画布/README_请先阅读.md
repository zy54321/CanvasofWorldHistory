## 3. 当前已确认的关键决策

- 产品名称：世界历史时空画布。
- 核心体验：地图为主画面，时间轴为主要控制器；按时间观察世界各地事件，并可切换人物、地点视角。
- 地图供应商：MapTiler
  Cloud。用户已在实际网络环境中裸连测试，加载顺利，Outdoor、电子地图和卫星地图体验符合预期。
- 地图引擎：MapLibre GL JS。
- 默认地图样式：Outdoor；同时验证 Streets / Base、Satellite、Hybrid
  等账号当前可用样式。
- 不编辑底图，不自建地图瓦片，不建设矢量瓦片生产能力。
- 四类核心对象：时间、地点、人物、事件。**时间模型选择
  A：时间是统一维度，不是独立业务实体。**
- 地理优先：先解决古代地名与坐标，不强求映射到同名现代城市。
- 数据尽量本地化；地图底图继续在线使用 MapTiler。
- 数据冲突不建设复杂裁决系统：一个正式主记录，保留最低限度来源信息，后续允许人工编辑纠正。
- 前端：Vue 3 + TypeScript。
- 后端：Spring Boot，模块化单体。
- 数据库：PostgreSQL + PostGIS。
- 部署：Docker Compose。
- 轻量化，不引入没有明确必要的中间件和微服务。

## 4. 第一轮任务边界

### 允许做

- 建立独立、可丢弃的 MapTiler + MapLibre 最小验证页面。
- 使用用户本地安全配置的 MapTiler API key 进行验证。
- 下载少量公开数据样本，分析结构、坐标、覆盖范围、来源和许可。
- 输出截图、测试记录、字段映射表和建议。

### 暂不允许做

- 不搭建正式生产项目骨架。
- 不初始化正式数据库，不创建正式 Migration。
- 不进行 Pleiades、WHG、CHGIS、MCGD 全量下载或全量导入。
- 不自行决定最终数据合并结果。
- 不擅自更换已确认技术路线。
- 不接入 AI 模块。
- 不进行公网部署。
- 不提交、推送代码或修改用户其他项目。
- 不将 API key / token 写入源代码、日志、截图或交付文档。
