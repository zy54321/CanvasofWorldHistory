# WB-002｜历史地理数据源验证任务书

**优先级：** P0  
**性质：** 数据源调查与小样本验证  
**执行方式：** 可与 WB-001 并行  
**交付后：** 等待 Owner 验收，不自动进行全量导入

## 1. 验证目标

确认 Pleiades、World Historical Gazetteer（WHG）、CHGIS、MCGD
对《世界历史时空画布》的实际价值： - 数据覆盖哪些时期和地区。 -
是否提供历史名称、别名、经纬度、几何、年代和外部 ID。 -
坐标参考系是否明确。 - 数据能否下载并本地保存。 - 许可允许怎样使用。 -
数据之间有哪些重叠和互补。 -
如何以最少清洗成本建立第一批本地历史地点数据。

第一阶段优先解决古代地名与地理坐标，不要求先导入完整事件和人物资料。

## 2. 数据源清单

### Pleiades

重点检查： - 古典地中海及周边古代地点覆盖。 -
place、name、location、connection 等字段。 - 坐标和位置精度。 -
数据快照/版本下载方式。 - CC BY 3.0 署名及修改说明要求。

### World Historical Gazetteer（WHG）

重点检查： - 全球历史地名聚合范围。 -
名称、几何、时间、来源和关联字段。 - API 与批量数据获取能力。 -
数据集级许可、source license、redistributable 等标记。 - 不得假定所有
WHG 聚合记录共享同一许可。

### CHGIS

重点检查： - 中国历史行政地理覆盖范围和时间边界。 - 秦代至 1911
年的覆盖对本项目的价值和空白。 - 地名、行政层级、时间、几何和 ID
字段。 - 学术使用与再分发边界。 - 不得将 CHGIS
当作覆盖先秦所有古地名的完整数据源。

### MCGD

重点检查： - 中国历史文献地名、中文名、拼音/转写、坐标、内部 ID。 -
数据集当前版本、更新日期和实际文件结构。 -
坐标系、精度、来源和年代字段。 -
许可文本是否明确；不明确时标记为待确认，不默认可再分发。

## 3. 样本策略

只下载少量代表性样本，不做全量数据抓取。

建议样本区域： - 中国：关中、洛阳及中原地区。 -
地中海：罗马、雅典及周边。 - 西亚：两河流域或黎凡特区域。

样本应尽量覆盖： - 有明确点坐标的地点。 - 只有区域几何的地点。 -
多个历史名称的地点。 - 同名异地或疑似重复地点。 -
带年代信息和不带年代信息的记录。

若某数据源不覆盖某样本区域，记录为覆盖缺口，不强行寻找替代记录。

## 4. 字段分析要求

每个数据源都要输出：

| 字段类别 | 要确认的内容                             |
|:---------|:-----------------------------------------|
| 身份     | 外部 ID、规范名称、记录稳定性            |
| 名称     | 原名、别名、语言、转写、异体字           |
| 空间     | 经纬度、geometry、CRS、精度、不确定性    |
| 时间     | 起止年代、年代精度、有效期               |
| 关系     | 关联地点、来源、上下级或相关对象         |
| 来源     | 数据集、贡献者、史料或引用信息           |
| 许可     | 许可名称、署名要求、修改说明、再分发边界 |
| 版本     | 下载日期、数据版本、文件格式、校验值     |

不得只给”字段齐全/不齐全”的主观判断，要列出真实字段名和样本记录。

## 5. 坐标规范验证

本项目业务数据库目标坐标系为 WGS84 / EPSG:4326。

必须核实每个数据源： - 官方声明的 CRS。 -
坐标轴顺序（经度/纬度或纬度/经度）。 - 坐标是否为 WGS84。 -
是否存在地方坐标体系或未知坐标体系。 - 是否有坐标精度或误差说明。

对于无法确认 CRS
的数据，不得直接导入正式地点表。保留原始坐标和来源信息，列为待核实记录。

## 6. 数据重叠与匹配分析

以样本为基础比较： - 外部 ID 是否可用于跨版本识别。 -
名称相同但坐标不同的情况。 - 坐标相近但名称不同的情况。 -
同一地点在不同年代发生名称或位置变化的情况。 -
一个来源是点、另一个来源是区域几何的情况。

建议给出”候选匹配”结果和人工复核清单。不得仅凭同名或距离阈值自动合并正式地点。

## 7. 推荐输出

1.  `DATA_SOURCE_MATRIX.md`：四个来源的覆盖、字段、格式、许可、优缺点比较。
2.  `FIELD_MAPPING.xlsx` 或 CSV：来源字段到项目地点模型的映射。
3.  `sample_data/`：每个来源少量原始样本，保留原文件结构。
4.  `SAMPLE_RECONCILIATION.md`：样本重叠、同名异地、坐标差异及候选匹配。
5.  `LICENSE_REVIEW.md`：逐数据源、逐数据集的许可核查；无法确认的明确标记。
6.  `IMPORT_RECOMMENDATION.md`：第一批建议导入来源、区域、字段映射、风险和工作量。
7.  `README.md`：样本来源、版本、下载日期、校验值和复现方式。

## 8. 许可与数据保存边界

- 不把”可下载”直接等同于”可自由再分发”。
- WHG 逐数据集检查许可。
- CHGIS 的学术使用边界和再分发许可需明确核对。
- MCGD 许可未确认前，不纳入可公开再分发的数据包。
- Pleiades 按 CC BY 3.0 要求保留署名和修改说明。
- 记录数据版本、下载日期和文件校验值。
- 不将未经许可确认的数据样本上传到公开仓库。

## 9. 通过标准

- 四个数据源均有真实样本或明确记录其不可获取原因。
- 样本字段分析具体到字段名。
- 坐标系和坐标轴顺序已核实或明确标记未知。
- 数据覆盖范围和时间范围有证据。
- 许可情况有官方来源支撑；不确定项没有被包装成确定结论。
- 输出字段映射和第一批导入建议。
- 没有进行未经批准的全量下载、全量导入或自动合并。

## 10. 停止条件

完成样本验证和报告后停止。不得创建正式数据库或导入正式业务数据。等待
Owner 审查后，再决定数据模型细化和导入顺序。
